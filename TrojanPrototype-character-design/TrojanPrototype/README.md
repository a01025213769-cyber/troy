
## 플레이 흐름

1. 탭으로 스토리 컷신을 진행합니다.
2. 아킬레우스로 적 병사 3명을 연속 격파하는 다대다 전투를 진행합니다. 전장에는 양 진형이 보이고, 각 적은 간결한 턴 기반 전투로 표현됩니다.
3. 헥토르와 일대일 보스전을 치릅니다.
4. 결과 화면에서 탭하면 다시 시작합니다.

## 조작

- 공격: 적에게 피해를 주고 집중을 모읍니다.
- 방어: 다음 반격 피해를 줄입니다.
- 필살기: 집중 50%를 사용해 큰 피해를 줍니다.

캐릭터 아트는 제공된 픽셀 스프라이트 시트의 아킬레우스, 헥토르, 그리스 병사, 트로이 병사를 사용합니다. 배경과 인터페이스는 Canvas로 그린 프로토타입입니다.
