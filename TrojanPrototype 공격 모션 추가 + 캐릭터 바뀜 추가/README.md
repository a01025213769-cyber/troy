# 트로이 전쟁 — 얼굴, 전쟁, 남자, 생각 그리고 속임수

영화 《오디세이》의 배경이 된 트로이 전쟁을 짧은 2D 격투 대전으로 체험하는 Android 게임입니다.
10조 · 심신 · 유장원 / Android Studio + Java / SurfaceView + Canvas

---

## 1. 이번 버전에서 새로 들어간 것

| 내용 | 위치 |
|---|---|
| **동작 프레임 애니메이션** (대기·걷기·공격·방어) | `util/SpriteSet.java`, `ui/BattleRenderer.java` |
| **캐릭터 선택 화면 제거** — 주인공은 스토리가 결정 | `core/GameEngine.java`, `data/GameData.java` |
| **아킬레우스 사망 → 오디세우스 교체 연출** | `data/StoryData.java`, `ui/Screens.java` |
| **오디세우스의 활 (원거리 화살)** | `data/GameData.java`, `battle/BattleWorld.java` |
| 마지막 전투 추가 (오디세우스 vs 왕궁 수비대장) | `data/GameData.java` |

난이도 선택은 발표 시연(AI 반응 속도 비교)에 필요해서 **타이틀 화면으로 옮겨** 남겨 두었습니다.

## 2. 게임 흐름

```
타이틀 (난이도 선택) ─► 프롤로그: 불화의 시작 (황금 사과)
         │
   1장 전쟁의 발발     ─► 전투 1  아킬레우스 vs 트로이 병사    ─► 결과 + 해설
   2장 끝나지 않는 전쟁 ─► 전투 2  아킬레우스 vs 트로이 정예병  ─► 결과 + 해설
   3장 영웅들의 대립    ─► 보스전  아킬레우스 vs 헥토르        ─► 결과 + 해설
         │
   4장 아킬레우스의 최후  ★ 파리스의 화살에 쓰러짐 → 주인공이 오디세우스로 교체
         │
   최종전  오디세우스 vs 왕궁 수비대장 (트로이 함락)          ─► 결과 + 해설
         │
   5장 귀향의 시작 ─► ODYSSEY · The Journey Home ─► 타이틀
```

패배하면 결과 화면에서 **같은 전투만** 다시 도전합니다. 이야기는 뒤로 밀리지 않습니다.

## 3. 동작 애니메이션

`res/drawable-nodpi/<이름>_f0.png` ~ `_f5.png` 6장을 쓰며, 번호의 뜻은 다음과 같습니다.

| 프레임 | 동작 | 게임에서 쓰이는 곳 |
|---|---|---|
| f0 | 대기 1 | 가만히 있을 때 (f1과 번갈아) |
| f1 | 대기 2 | 대기 / 공격 선딜 / 피격 |
| f2 | 걷기 | 이동 · **오디세우스의 검 공격** (검을 앞으로 뻗은 그림) |
| f3 | 달리기 | 이동 / 회피 |
| f4 | 공격 | 공격 판정 구간 (활은 선딜부터) |
| f5 | 방어 | 방어 버튼을 누르고 있을 때 |

**그림을 화면에 맞추는 규칙** (`util/SpriteSet.java`)

프레임 6장은 모두 같은 캔버스를 쓰고, 캔버스 아래가 발, 캔버스 가로 중심이 몸 중심입니다.
그래서 캔버스를 통째로 그리되 아래를 바닥선에, 가로 중심을 캐릭터 좌표에 맞춥니다.
이렇게 하면 공격 프레임의 긴 창이 자연스럽게 앞으로 뻗고, 프레임이 바뀌어도 캐릭터가 덜컹거리지 않습니다.

캐릭터마다 캔버스 여백이 달라서, **f0에서 몸이 실제로 차지하는 높이를 코드가 직접 재어** 키를 맞춥니다.
그림을 바꿔도 코드를 고칠 필요가 없습니다.

**새 캐릭터를 추가하려면** `res/drawable-nodpi/` 에 `이름_f0` ~ `이름_f5` 를 넣고
`GameData` 의 `spriteName` 에 `"이름"` 을 적으면 끝입니다. 프레임이 없으면 한 장짜리 그림으로 자동 대체됩니다.

## 4. 두 주인공

| | 아킬레우스 (1~3장) | 오디세우스 (최종전) |
|---|---|---|
| 무기 | 긴 창 — 근접 | **활(원거리) + 돌진 검(근접) 자동 전환** |
| 체력 | 100 (낮음) | 126 |
| 특징 | 사거리가 길고 공격이 빠름 | 거리에 따라 싸우는 방식이 바뀜 |
| 필살기 | 분노의 돌격 (4연타 돌진) | 연속 사격 (화살 5발) |

**오디세우스의 무기 전환**

적과의 거리가 `ODYSSEUS.meleeRange`(기본 **275px**)보다 멀면 활로 화살을 쏘고,
그 안으로 들어오면 자동으로 **검**으로 바뀝니다.
지금 어떤 무기가 나갈지는 **공격 버튼 아래에 "활 · 원거리" / "검 · 근접"** 으로 표시됩니다.

검은 제자리에서 휘두르는 게 아니라 **파고들어 베는 돌진 공격**입니다.
스프라이트의 검은 몸 중심에서 40px 남짓이라, 판정 상자만 길게 늘리면
닿지도 않은 허공에서 적이 맞는 것처럼 보입니다.
그래서 판정은 적당히 두고(돌진 베기 92px) **전진 속도를 크게 올려**
먼 거리에서도 몸이 따라 들어가 베도록 했습니다. 맞히는 순간 전진이 멈춰서
상대를 뚫고 지나가지 않습니다.

활은 선딜이 길어 붙은 상대에게 불리하고, 검은 빠르지만 붙어야 합니다.
그래서 마지막 장은 "거리를 관리하는 싸움"이 되고, "힘이 아니라 머리로 싸운다"는 이야기와 맞아떨어집니다.

전환 거리를 바꾸려면 `GameData.ODYSSEUS` 의 마지막 숫자(`275f`)만 고치면 됩니다.
더 멀리서 검을 쓰게 하려면 `돌진 베기` 의 전진 값(`1250f`)도 같이 올려야
돌진이 그 거리를 따라잡습니다.

## 6. 발표 시연 추천 순서

1. 타이틀에서 **난이도를 쉬움↔어려움으로 바꿔 보이며** AI 판단 주기 차이 설명
2. 프롤로그 컷신 (황금 사과 → 전쟁의 원인)
3. 전투 중 **[AI] 버튼** 을 켜고:
   - 7가지 행동 점수 막대가 실시간으로 바뀌는 것
   - "상대 후딜 포착 → 반격", "막을 수 없는 공격 → 회피" 같은 판단 근거
4. **방어만 눌러 보여 주기** → 적이 가드 브레이크(강공격)로 전환하는 장면
5. 보스전 승리 → **4장에서 아킬레우스가 쓰러지고 오디세우스로 바뀌는 연출**
6. 최종전에서 **멀리서는 활, 붙으면 검으로 바뀌는 것**을 보여 주기 → ODYSSEY 엔딩

## 7. 적 AI (과목 핵심)

`ai/EnemyBrain.java` — FSM + 유틸리티 점수 방식

난이도마다 정해진 간격(쉬움 0.58초 / 보통 0.34초 / 어려움 0.22초)마다
7가지 행동(대기·접근·후퇴·공격·강공격·방어·회피)에 점수를 매겨 가장 높은 것을 고릅니다.
점수는 **거리 / 자기 체력 / 상대가 지금 뭘 하고 있는지** 로 정해집니다.

들어 있는 판단 규칙

- 상대가 공격을 시작하면 → 방어 또는 회피 점수 상승
- 그 공격이 **강공격(막히지 않음)** 이면 → 방어를 버리고 회피
- 상대가 **방어 중**이면 → **가드 브레이크(강공격)** 점수를 크게 올림
- 0.85초 넘게 막고만 있으면 → 방어 점수를 낮추고 공격으로 전환
- 막아 낸 직후 / 회피 직후 → 반격 점수 상승
- 체력 35% 아래 → 후퇴 / 보스는 **분노** 상태로 공격적 전환

## 9. 자주 바꿀 만한 것

**밸런스** — `data/GameData.java` 의 숫자만 고치면 됩니다.

```java
// Move(이름, 선딜, 판정, 후딜, 사거리, 높이, 위치, 피해, 넉백, 전진, 횟수, 분노, 가드브레이크)
new Move("창 찌르기", 0.11f, 0.09f, 0.18f, 130f, 64f, 112f, 10f, 150f, 40f, 1, 9f, false)
```

- 너무 쉬우면 → `DIFFICULTIES` 의 `reactionTime` 을 줄이거나 `enemyHp` 를 올립니다
- 공격이 둔하면 → `windup`(선딜)을 줄입니다
- 사거리는 공격 프레임(`_f4`)의 무기 끝에 맞춰 두었습니다. 그림을 바꾸면 같이 조정하세요

**소리** — `res/raw/` 에 아래 이름으로 파일만 넣으면 자동 재생됩니다. 없으면 무음으로 정상 동작합니다.

```
효과음: sfx_swing, sfx_hit, sfx_heavy, sfx_guard,
        sfx_dodge, sfx_ultimate, sfx_win, sfx_lose, sfx_select
배경음: bgm_title, bgm_story, bgm_battle, bgm_boss
```

> ⚠️ **`res` 폴더 안의 파일 이름 규칙**
> 소문자 `a-z`, 숫자 `0-9`, 밑줄 `_` 만 쓸 수 있습니다. 대문자나 하이픈이 들어가면 빌드가 실패합니다.
> ```
> ❌ README.txt, Sfx_Hit.wav, bgm-title.mp3
> ✅ readme_sound.txt, sfx_hit.wav, bgm_title.mp3
> ```

## 10. 전투 규칙 요약

- 공격은 **선딜 → 판정 → 후딜** 3단계입니다. 후딜 중에 맞으면 반격당합니다.
- 방어는 피해를 75% 줄이지만 **강공격은 막지 못합니다.** 강공격은 회피로 피해야 합니다.
- 회피는 0.05초~0.26초 구간이 무적입니다.
- 연속으로 6대를 맞으면 밀려나면서 잠깐 무적이 됩니다 (**무한 콤보 방지**).
- 근접 공격은 후딜 절반이 지나야 다음 공격으로 이어집니다. 활은 이어 쏠 수 없습니다.
- 제한 시간이 끝나면 체력 비율이 높은 쪽이 이깁니다.
