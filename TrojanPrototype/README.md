# 트로이 전쟁 — 얼굴, 전쟁, 남자, 생각 그리고 속임수

영화 《오디세이》의 배경이 된 트로이 전쟁을 짧은 2D 격투 대전으로 체험하는 Android 게임입니다.
10조 · 심신 · 유장원 / Android Studio + Java / SurfaceView + Canvas

---

## 1. 이번에 구현된 것

발표 PPT의 MVP 범위(스토리 3개 전투 · 플레이어 2명 · 적 2종 · 이동/공격/방어 · 체력과 승패 · 재시작 · 대사와 결과 해설)를
실제로 돌아가는 형태로 구현했습니다.

| PPT 항목 | 구현 위치 |
|---|---|
| 화면 전환 (타이틀→컷신→선택→전투→결과→엔딩) | `core/GameEngine.java` |
| SurfaceView + Canvas, Update/Render 루프 | `core/GameSurfaceView.java` |
| 터치 입력 (멀티터치 가상 패드) | `core/TouchInput.java` + `ui/VirtualPad.java` |
| 이동 · 공격 · 방어 · 회피 · 필살기 | `battle/Fighter.java` |
| 충돌 판정 · 피해 · 승패 | `battle/BattleWorld.java` |
| FSM + 유틸리티 AI | `ai/EnemyBrain.java` |
| **AI 동작 시연 (판단 근거 화면 표시)** | `ui/AiDebugView.java` |
| 스토리 컷신 (페이드 + 한 줄씩 등장) | `data/StoryData.java` + `ui/Screens.java` |
| 사운드 연결 (파일만 넣으면 동작) | `audio/SoundManager.java` |

이전 버전(턴제 탭 전투)에서 **실시간 격투**로 바뀌었고, 파일이 역할별로 나뉘었습니다.

## 2. 실행 방법

1. Android Studio에서 `TrojanPrototype` 폴더를 엽니다.
2. `local.properties` 는 Android Studio가 자동으로 만들어 줍니다. (없어도 됩니다)
3. Gradle Sync 후 Run.

가로 화면 전용이며, 모든 좌표는 **960 x 540 가상 화면** 기준입니다.
기기 해상도가 달라도 `util/Viewport.java` 가 비율을 유지한 채 맞춰 줍니다.

## 3. 게임 흐름

```
타이틀 ─► 프롤로그: 불화의 시작 (황금 사과)
            │
            ▼
       캐릭터 · 난이도 선택
            │
   1장 전쟁의 발발    ─► 전투 1: 트로이 병사    ─► 결과 + 해설
   2장 끝나지 않는 전쟁 ─► 전투 2: 트로이 정예병  ─► 결과 + 해설
   3장 영웅들의 대립   ─► 보스전: 헥토르        ─► 결과 + 해설
            │
   4장 트로이의 함락 (목마) ─► 5장 귀향의 시작
            │
            ▼
      ODYSSEY · The Journey Home ─► 타이틀
```

패배하면 결과 화면에서 **같은 전투만** 다시 도전합니다. 이야기는 뒤로 밀리지 않습니다.

## 4. 조작

| 버튼 | 동작 |
|---|---|
| ◀ ▶ | 좌우 이동 (누르고 있으면 계속 이동) |
| 공격 | 탭하여 공격. **빠르게 연타하면 3타째에 강공격** (방어를 뚫음) |
| 방어 | 누르고 있는 동안 피해 75% 감소. 단 강공격은 막히지 않음 |
| 회피 | 짧은 무적. 적 공격 직전에 쓰면 완전히 피함 |
| 필살기 | 분노 100%에서 사용. 다단히트 |
| ⏸ | 일시정지 (계속 / 다시 시작 / 타이틀) |
| AI | **적 AI 판단 과정 표시 — 발표 시연용** |

## 5. 발표 시연 추천 순서

1. 타이틀 → **조작 방법** 버튼으로 조작 설명
2. 프롤로그 컷신 (황금 사과 → 전쟁의 원인)
3. 캐릭터 선택에서 **난이도를 '쉬움'과 '어려움'으로 바꿔 보이며** AI 판단 주기 차이 설명
4. 전투 중 **[AI] 버튼** 을 켜고:
   - 7가지 행동 점수 막대가 실시간으로 바뀌는 것
   - 선택된 행동이 금색으로 강조되는 것
   - "상대 후딜 포착 → 반격", "막을 수 없는 공격 → 회피" 같은 **판단 근거 문장**
   - 공격/몸통 판정 상자가 눈에 보이는 것
5. **방어만 눌러 보여 주기** → 적이 가드 브레이크(강공격)로 전환하는 장면
6. 보스전 → 엔딩 → ODYSSEY 타이틀로 영화와 연결

## 6. 적 AI 설명 (과목 핵심)

`ai/EnemyBrain.java`

**왜 if-else 가 아니라 점수(유틸리티) 방식인가**
조건이 늘어나면 if-else 는 분기가 폭발하고, "왜 그렇게 행동했는지" 설명하기 어렵습니다.
점수 방식은 조건 하나를 가중치 한 줄로 추가할 수 있고, 선택 이유를 숫자로 보여 줄 수 있습니다.

**동작 순서**

1. 난이도마다 정해진 간격(쉬움 0.58초 / 보통 0.34초 / 어려움 0.22초)마다 행동을 다시 고릅니다.
   이 간격이 곧 "사람의 반응 속도"이자 난이도입니다.
2. 7가지 행동에 점수를 매깁니다 — 대기 · 접근 · 후퇴 · 공격 · 강공격 · 방어 · 회피
3. 점수는 **거리 / 자기 체력 / 상대가 지금 뭘 하고 있는지** 로 결정됩니다.
4. 가장 높은 점수의 행동을 고르고, 다음 판단 때까지 유지합니다.

**들어 있는 판단 규칙**

- 상대가 공격을 시작하면 → 방어 또는 회피 점수 상승
- 그 공격이 **강공격(막히지 않음)** 이면 → 방어 점수를 낮추고 회피 점수를 크게 올림
- 상대가 **방어 중**이면 → 일반 공격 점수를 낮추고 **가드 브레이크(강공격)** 점수를 크게 올림
- 너무 오래 막고만 있으면(0.85초) → 방어 점수가 떨어지고 공격으로 전환 (가드 굳히기 방지)
- 막아 낸 직후 / 회피 직후 → 반격 점수 상승
- 체력이 35% 아래면 → 후퇴 점수 상승
- 보스는 체력 35% 아래에서 **분노** 상태가 되어 공격적으로 변함

## 8. 자주 바꿀 만한 것

**밸런스 조정** — `data/GameData.java` 의 숫자만 고치면 됩니다.

```java
// Move(이름, 선딜, 판정, 후딜, 사거리, 높이, 위치, 피해, 넉백, 전진, 횟수, 분노, 가드브레이크)
new Move("베기", 0.10f, 0.09f, 0.17f, 92f, 72f, 118f, 11f, 150f, 40f, 1, 9f, false)
```

- 너무 쉬우면 → `DIFFICULTIES` 의 `reactionTime` 을 줄이거나 `enemyHp` 를 올립니다
- 공격이 둔하면 → `windup`(선딜)을 줄입니다
- 적이 너무 소극적이면 → `aggression` 을 올립니다

**캐릭터 그림 교체** — `res/drawable-nodpi/` 에 png 를 넣고
`GameData` 의 `spriteName` 을 파일 이름으로 바꾸면 끝입니다. (자바 코드 수정 불필요)

**소리 넣기** — `res/raw/` 에 아래 이름으로 파일만 넣으면 자동으로 재생됩니다.
파일이 없으면 소리만 안 날 뿐 앱은 정상 동작합니다.

```
효과음: sfx_swing, sfx_hit, sfx_heavy, sfx_guard,
        sfx_dodge, sfx_ultimate, sfx_win, sfx_lose, sfx_select
배경음: bgm_title, bgm_story, bgm_battle, bgm_boss
```

**대사 수정** — `data/StoryData.java` 의 `lines` 배열에 문장을 넣으면 한 줄씩 나타납니다.

## 9. 전투 규칙 요약

- 공격은 **선딜 → 판정 → 후딜** 3단계입니다. 후딜 중에 맞으면 반격당합니다.
- 방어는 피해를 75% 줄이지만 **강공격은 막지 못합니다.** 강공격은 회피로 피해야 합니다.
- 회피는 0.05초~0.26초 구간이 무적입니다.
- 연속으로 6대를 맞으면 밀려나면서 잠깐 무적이 됩니다. (**무한 콤보 방지**)
- 제한 시간이 끝나면 체력 비율이 높은 쪽이 이깁니다.
